## Findings

- Both arms do these tasks; the Python arm passed all ten. Its agents
  repaired formulas by hand after openpyxl's `insert_rows`, rewrote table
  and chart ranges, and in two tasks patched stored results into the XML.
  On files this small, success does not separate the arms.
- Stored results separate them: 8/8 with `sheets`, 2/8 with Python. A file
  the Python arm leaves has no results for pandas, previews or the next
  tool until Excel opens it.
- `sheets` failed the formatting request (a light blue header, dollars
  without decimals): it has no way to style cells as asked.
- `sheets` used about 3k more tokens a run (its guide in the prompt) and
  slightly less time (285 s against 328 s in all).
- A `sheets` agent found the calculator storing wrong results for
  `SUMPRODUCT((range="x")*range)`: array arithmetic, since fixed by leaving
  such formulas to Excel.
