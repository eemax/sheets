# Our own tasks on three models, 2026-10-25

The 18 tasks in `evals/tasks`, run once on each of Sonnet, Haiku and
Opus, by all four arms of `evals/run.py`. That is 54 runs per arm, and
the same harness as the 2026-10-24 assessment.

## Verdict

After the trust fixes, sheets fails one run in 54 (it failed 6 in 50
before). That one was a sheets bug, the last assessment's bug 5, which
the earlier fix had only partly fixed; it is fixed now. Every arm does
these tasks. Two things still set sheets apart:

- **Stored results:** sheets is the only arm that leaves files with
  their formula results stored, 45 of 45. The others manage 0 to 4, so
  pandas, previews and other programs read empty cells until Excel opens
  the file.
- **Effort:** it takes about as many turns as plain Python, half as
  many as the MCP server, and the least time on Sonnet and Opus.

## Failures

- **sheets, task 18 (Sonnet).** The task raises prices in a German ERP
  export by 5%.
  - **What went wrong:** one price, 80,48, came out as `84,5` where the
    file writes `84,50`. This is the last assessment's bug 5. The
    earlier fix kept the text of values the file already held. But only
    numbers with thousands separators (`1.249,00`) were read with a
    two-decimal format, so a new value in a plain one still lost its
    trailing zero.
  - **Fix:** when sheets edits a CSV file, a number keeps the decimals
    it was written with, and gets no thousands separators if it had none
    (`csvtransform.txtar`).
  - **Check:** the agent's own commands, replayed, now pass all seven of
    the task's checks.
- **mcp, Haiku.** Task 12 left no `report.xlsx`; task 17 gave wrong
  totals for March and the year.

## Compared with 2026-10-24

The six sheets failures of the last assessment were these:

- **NPV:** a wrong NPV computed and stored, in four runs.
- **Table reference:** a reference into a sheet's table that Excel
  cannot read.
- **CSV decimals:** `84,5` for `84,50`.

The first two did not come back in these 54 runs; the third did, once,
and is now fixed. The arms' pass rates have converged: these tasks no
longer separate them. The harder benchmark
(`2026-10-25-spreadsheetbench.md`) does.
